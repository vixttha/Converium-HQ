# Converium HQ roadmap

These versions describe knowledge-repository maturity, not product releases.

| Version | Objective | Acceptance | State |
| --- | --- | --- | --- |
| v0.0.1 | Constitution and permanent knowledge | Six exact laws, scope, decisions, state, history, handoff, entry point | Accepted |
| v0.0.2 | Six-product registry | Six independent profiles, exact source pins, authoritative refs, release distinctions | Accepted |
| v0.0.3 | Historical evidence library | Preserve exact audit records, manifest, reproducible validation and honest claims | Accepted |
| v0.0.4 | Graphify ecosystem mapping | Pin a graph of products, decisions and evidence; verify actual links and graph receipt | Accepted |
| v0.0.5 | Notion knowledge dashboard | Read-only navigation and source links, no duplicate canonical records | Accepted |
| v0.0.6 | Fresh-agent knowledge recovery | Fresh ChatGPT and alternative compatible harness reconstruct state, identify stale sources, respect boundaries | Notion trial 6/8; targeted retest improved receipt recovery; fresh ChatGPT pending |
| v0.0.7 | Brand identity | Owner-approved visual system and name review, no assumed trademark clearance | Candidate; owner and clearance pending |
| v0.0.8 | Commercial strategy | Audience, license scope, honest evidence claims, offer and owner decisions | Candidate; owner decisions pending |
| v0.1.0 | First accepted HQ baseline | Review all prior gates, resolve or explicitly defer blockers, owner approves exact baseline | Review candidate; gates pending |

Foundation scope is [#1](https://github.com/vixttha/Converium-HQ/issues/1). Completion of candidate checks does not imply owner integration or release. Subsequent milestones require distinct work and acceptance. No seventh software product, shared runtime or mandatory dependency.
