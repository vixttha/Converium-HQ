## Claim boundaries

- Actual practical use across the toolkit is demonstrated. Historical sample is not exhaustive and not every tool was used for every task.
- Compatibility covers pinned fixture branch coexistence and smoke checks, not 63 remote installations, every runtime path or every LLM.
- The [benchmark pilot](imported/2026-11-24/benchmark-pilot-1.md) recorded 7/8 on both arms, 9 vs 15 observed tool calls, unknown model identity/tokens/time/cost. The expected version was scored even though task wording did not explicitly demand a version string; scoring was documented after launch but before results. Preserve the original record, but do not describe it as a fully preregistered controlled trial or a productivity gain.
- [Historical commercial proposal and licensing inventory](imported/2026-11-24/COMMERCIAL-OFFER.md) is planning, not permission to distribute. Converium is the selected HQ name; final public branding, name clearance, pricing and launch remain pending.
- Imported scripts and pins are archival verification recipes. Their original workflow context and results live in the originating repository. HQ does not install or operate any product. No private agent URLs or credentials are copied.

## Reproduce HQ validation

The public runner additionally uses `--remote` to read exact public source bytes for archived files, product entry points and six-law parity. It does not run the historical product suites, claim a new benchmark or make any remote writes. Historical source metadata and runs remain pinned references.
