## Proposed system

- Primary ink: #11253A; accent: #176B62; light canvas: #F7F9F8; dark canvas: #11253A; dark-mode accent: #8CD9C2; dark text: #F7F9F8.
- Typography: native system sans serif, with monospaced technical metadata. No proprietary font included. Plain, clear language; no AI mascot or excessive decoration.
- Product brands remain independent; HQ navigation uses neutral role labels and may link to product-owned marks but may not redesign or claim them.
- Visual hierarchy: wordmark + short descriptor, then clear headings and evidence links. Do not equate graph connections to runtime dependencies.
- Accessibility: text foreground/background combinations are tested mechanically for 4.5:1 contrast. Symbols need accessible labels and optical review; passing XML and contrast is not a visual approval.
