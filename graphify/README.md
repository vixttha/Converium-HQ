# Converium relationship map (v0.0.4 candidate)

This read-only knowledge projection of [accepted foundation](https://github.com/vixttha/Converium-HQ/tree/dc77ba9abe1e18fb9d27a12814213ce9acded31a) maps the six products, laws, decisions and 23 historical evidence cases. Fourteen directed operational relationships are distinct from two feedback cases, six self-use/self-validation cases and one external BART adoption. A relationship is not a runtime dependency or causal claim. Drafts retain their classification. HQ is a knowledge node, not a product. The pinned inputs and Graphify package provenance are in [pins.json](pins.json).

## Reproduce
The public runner installs the exact hash-locked Graphify wheel set from the previously tested Graphify HQ v0.0.8 lock, uses its documented build/export and MCP APIs with a Converium-specific projection, verifies the directed edge set and hashes, rebuilds twice, and uploads graph.json, receipt.json and semantic.json. No third-party service, LLM, paid runner or product install is required. This is not an execution of the original feature-evidence manifest tool: its model is feature-to-source, not product-to-product. The independent projection preserves the actual typed relationships. Output and receipt are supplied by successful CI, not assumed here. [Plan](PLAN.md).
